# RANA Hostel Election Website

## Files
- `index.html` — website
- `style.css` — styling
- `script.js` — smooth navigation

## Contact form
The form is configured with FormSubmit to forward messages to:
`ranacampus07@gmail.com`

On the first submission, FormSubmit may require email activation/confirmation. Complete that once.

## Deploy on Vercel
1. Create a GitHub repository and upload these three files.
2. Import the repository into Vercel.
3. Deploy with no build command.
4. Your Vercel URL can then be used in the campaign QR code.

## Important
The QR code should be generated only after the final deployed URL is known, so it points to the real website.
